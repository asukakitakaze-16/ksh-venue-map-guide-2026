# 会場MAP・目的別歩き方ガイド 実装確認版

Googleスライド431・432ページの提案内容と、2026年10月1日版の小間図を基にしたローカル確認版です。

## 実装ページ

- `map-design.html`
  - 技術図面をブース島と通路に整理した、パンフレット風会場MAPの単体プレビュー
  - A〜L、目的別の色分け、4つの注目企画、メイン入口、凡例を掲載
- `map-design.css`
  - 掲載用会場MAP単体デザインのスタイル
- `assets/venue-map-brochure-v2.png`
  - パンフレット風会場MAPのデザイン確認画像
- `index.html`
  - TOPページのWebガイド導線の下に「会場MAP」を追加
  - パンフレット風会場MAPを掲載
  - 来場者ページの「目的別・会場歩き方ガイド」へ誘導
- `visit.html`
  - 「3つのリアルな課題」に、それぞれの解決につながる出展者一覧ボタンを追加
  - 「同時開催される2つの展示会」の直後にパンフレット風会場MAPを追加
  - その直後に「目的別・会場歩き方ガイド」を追加
  - 省人化・DX、食材・新製品、海外販路・輸出相談、セミナー・実演の4ルートを掲載
- `solutions.html`
  - 人手不足・省人化、改修・リノベ、インバウンドの3課題で出展者を切り替え表示
  - 会社名・製品説明・ブース番号のページ内検索に対応
  - 各社の公式Webガイド詳細ページへ誘導
- `solution-data.js`
  - 公式Webガイドの登録情報を課題別に整理した表示データ
- `build-solution-data.py`
  - 公式Webガイドの検索結果から `solution-data.js` を再生成する作業用スクリプト
- `venue-guide.css`
  - 上記2ページで共通利用する追加スタイル
- `assets/venue-map-2026.png`
  - 2026年10月1日版小間図の来場者向けページ画像

## 実装時の注意

- パンフレット風MAPはデザイン確認用です。正式掲載時は最終小間図に合わせて、各ブロックの位置・形・小間情報を確定してください。
- 会場MAPの注記日付は「2026年10月1日現在」です。
- 課題別一覧は公式Webガイドの会社名・製品説明等を関連キーワードで抽出し、重複を除いています。
- 現在の掲載数は、人手不足・省人化19社、改修・リノベ27社、インバウンド16社です。
- 公式Webガイドの登録内容が更新された場合は、課題別一覧も再確認してください。
- 出展内容や小間配置に変更が出た場合は、画像と歩き方ガイドのブロック表記を更新してください。
- 既存サイトへ反映する際は `venue-guide.css`、`solution-data.js`、`assets/venue-map-brochure-v2.png` を同じ相対構成で配置してください。
